# Weekly Chars

Earn your voice, one character at a time

## The Problem

In April 2015, Kanye West posted more than 200 tweets in 10 hours. [[1]](https://www.xxlmag.com/kanye-west-wild-random-tweets/?utm_source=schmkls.github.io)

Today, many feeds are dominated by a AI and a few high-volume posters, while everyone else gets buried. Social platforms reward output volume over signal, so attention gets concentrated instead of distributed.

## Solution

A social platform where every user gets a weekly character budget: one of each character (including emojis) — one *a*, one *b*, one 🚀, and so on. To write a post, you can only use the characters you currently have. There are no likes or upvotes — only character transfers. Profiles show:

- posts (text + author + characters received)
- current character inventory (how many of each character)

This is an experiment in increasing **distributional diversity** in communication: less spammy output, more intentional expression, and a way to give people you value more voice.
