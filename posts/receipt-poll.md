# Receipt Poll

More drinks = better music

## The Problem

DJs get swarmed by drunk guests asking for “just one song.” The energy is real, but the process is chaos and doesn't create value for the club.

## The Solution

Turn requests into interaction through purchases. Every bar receipt includes a QR code. Guests scan it to vote between two song alternatives, so the crowd still shapes the night, but in a way that is fun, structured, and tied to revenue.

This should probably be an integration to [Soundtrack.io](https://www.soundtrack.io/)
